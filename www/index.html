⬡ Integrated Intelligence Workbench

A practical bridge from raw time-series data to reproducible analysis, model comparison, exploratory relationship maps and explicit research questions. It works in this page without sending your dataset to a server.

Offline · user controlled

Observe → model → challenge → record

The workbench computes descriptive statistics, gradients, correlations, lagged predictive links, ridge forecasts, an AR(1)-aware Gaussian empirical-Bayes change-point comparison, correlation-matrix eigenvalues, and fixed-threshold graph cycle rank. Every output carries its assumptions and limitations.

Local data processingChronological holdoutEvidence-aware JSONNo automatic upload

Not a magic-causality button

Temporal prediction helps generate testable candidates; it does not establish causation. The change-point result depends on the selected Gaussian model and its baseline. Ordinary graph cycles are not persistent homology. Consciousness and unknown physics are not inferred by a numerical score.

Research mode only. Do not use the current prototype to control machinery, diagnose people, make financial decisions, or certify scientific claims.
01 / Ingestion + provenance

Bring in a local dataset

The raw CSV stays in this page session

Paste CSV text or choose a local CSV file. Use one header row and regularly spaced observations. Numeric time/index columns are recognized when the first header is named time, timestamp, datetime, date, index, step, sample, record or t. At least two numeric signal columns and 12 observations are required. The analysis does not upload or persist the raw data.

Units are labels entered by you, not inferred or verified. Trend values are reported per observation row.

Signal summary

Means and sample standard deviations use stable online updates. Trend is an ordinary least-squares slope per row, not a physical derivative unless sampling and units support that interpretation.

04 / Relationships + forecasting

Multivariate relationship analysis

Matrix convention for the exported predictive-coefficient map is B[target, source]: the coefficient is for source observed at row t when predicting target at row t+1. This is a predictive convention, not a causal guarantee.
Same-row correlation matrix

Symmetric association. It does not encode direction or identify causes.

Lag-one association ranking + standardized ridge coefficients

Correlation compares source(t) with target(t+1). Model coefficients come from a multivariable ridge regression with a chronological train/test split.

Out-of-time prediction comparison

Compares multivariate ridge forecasting with a persistence baseline on the same chronological holdout. Lower RMSE/MAE is better; improvements depend on the dataset.

05 / Bayesian evidence

Single mean-change hypothesis

Select a signal after analysis.

Adjust this assumption from 5% to 50%; the result changes because the prior is part of the model, not because the data changed.

Run analysis to compare a no-change model with a one-change model.

The reported posterior is conditional on: one Gaussian mean change, a noise scale estimated from the first third, Gaussian residuals and a 20% prior probability of a change. It is empirical-Bayes, not a universal calibrated probability. Inspect the split and raw series before concluding.
06 / Spectral + graph structure

Eigenvalues & topology-lite

Eigenvalues are computed from the symmetric correlation matrix using a Jacobi rotation solver. The threshold graph uses absolute Pearson correlation. Its cycle rank (β₁ for the graph's cycle space) is E − V + connected components.

Run analysis to see the spectrum.

This is not persistent homology, tomography, a 3D reconstruction, or proof that variables are physically linked. Graph structure changes when the threshold changes.
07 / Evidence, lexicon + hypothesis testing

Make the synthesis falsifiable and terms operational

Record what kind of evidence a statement represents. Use the operational lexicon to define project terms so semantic similarity is not mistaken for scientific confirmation. These fields are user-provided metadata and are not independently checked.

Blank lexicon is allowed. If entered, each term must have a non-empty definition and be unique (case-insensitive). Definitions organize your terminology; they do not prove a claim. Evidence notes and glossary entries are included in exports—do not enter passwords or private customer/personal records.

The standard JSON packet contains statistics, model parameters, coefficients, uncertainty assumptions, integration status, user-provided evidence notes and limitations—not the original CSV. Exporting the raw CSV is a separate explicit action. Review the packet before sharing.

What is actually integrated?

The UI and the browser-side analytics are implemented here. Cross-project execution is not claimed unless an actual adapter calls the other project's code and is tested against it.

Recommended responsibility boundaries
INN System source was not accessible in this audit beyond earlier inventory references to runner.py, controllers/engine.py, simulation/physics.py and energy/fault tests. Analysis interpretation checklist

Do this before synthesis
  • Confirm the raw data source, units, timestamp spacing and calibration.
  • Examine missing/excluded rows and whether complete-case filtering changes the sample.
  • Compare ridge forecasts against the baseline and inspect errors over time.
  • Treat a lagged edge as a hypothesis; test confounders, reverse paths, temporal stability and interventions.
  • Record the alternatives and test that could falsify the preferred explanation.
  • Save/export the data and packet before clearing the page or changing devices.

Evidence update calculator

Apply Bayes' rule to a stated prior and likelihoods. This updates a probability only if the likelihood inputs are defensible for the specific evidence and hypothesis; it does not establish those inputs for you.

Ready.

02 / Linear algebra & optimization

Gradient and eigenvalue bench

Analyze the explicitly defined quadratic f(x,y) = ½ax² + bxy + ½cy² + px + qy. The Hessian is the symmetric matrix [[a,b],[b,c]]. Values are mathematical diagnostics for this model, not a general AI cognition score.

Ready.

Eigenvalues are exact closed-form eigenvalues of a real symmetric 2×2 Hessian. A suggested gradient step is not guaranteed to converge for every step size or objective.

03 / Telemetry & temporal relationships

Lead–lag association test

Compare contemporaneous correlation with one-step lagged correlations. Samples are assumed aligned and equally spaced. This can reveal temporal association; correlation and lead–lag do not establish causation.

Ready.

No hidden confounder adjustment, significance test, intervention, autocorrelation correction or causal identification is performed here.

04 / Topological data analysis

Point-cloud H₀ persistence

For a small 2D point cloud, compute Euclidean distances and the minimum spanning tree. Its sorted edge lengths are the finite death scales for connected components in a Vietoris–Rips H₀ filtration. This does not compute loops (H₁) or higher homology.

Ready.

The result depends on coordinate scaling and the chosen metric. Units and sampling must be meaningful before interpreting it scientifically.
